Additional live contract checks on the full-surface build:

- `send_code` succeeds without an extra host opt-in. Compile errors include
  diagnostics. Runtime and Inventor ErrorManager errors abort the wrapper
  transaction; native iProperty readback confirmed the prior value in both cases.
- A host warning and captured stdout are returned with a successful script.
- A 70,000-character script result spills to a local file with preview, schema,
  `mutation_applied: null`, readback and no-replay guidance. The full spill was read.
- A custom 4,096-byte budget rejects an oversized parameter read, compacts a
  completed multi-document write and spills script output. With the guard off,
  the read succeeds; a 4,096-byte transport cap still rejects it.
- With call-log/body-retention switches off, tracked gateway/add-in call logs
  remained unchanged through the script sequence. Script bodies were not added
  to a persisted journal. Explicit saved helper modules were deleted afterward.

This record covers Inventor 2027 only. It does not establish other host-year
acceptance, Claude Desktop extension lifecycle/permissions, or publication of
release assets. Public automated coverage is in `tests/stdio/release-contract.py`
(every MCP wrapper), the unit tests and the WPF toast harness; no-target error-path
results remain separate from the live successes above.
